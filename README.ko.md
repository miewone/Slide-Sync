# Slide Sync

**여러 슬라이드에 반복되는 요소를 한 번에 선택하고 정렬하는 브라우저 PPTX 편집기입니다.**

슬라이드마다 제목이나 도형의 위치를 맞추는 반복 작업을 줄여 줍니다. PPTX를 열고, 수정할 슬라이드와 요소를 선택한 뒤, 이동·정렬 결과를 새 PPTX 파일로 다운로드하세요. 파일 처리는 브라우저 안에서 이루어지며 서버에 업로드하지 않습니다.

[English](README.md) · [기능 위키](docs/wiki.md) · [개발 안내](docs/development.md) · [Cloudflare 배포](docs/deployment.md)

## 주요 기능

| 기능 | 할 수 있는 작업 |
| --- | --- |
| 여러 슬라이드 동시 편집 | 전체 또는 일부 슬라이드를 적용 대상으로 지정하고, 같은 위치의 요소를 함께 선택·이동 |
| 문자열로 슬라이드 선택 | 슬라이드 본문을 검색해 일치하는 슬라이드를 적용 대상에 추가하거나 해제 |
| 문자열로 요소 선택 | 체크한 슬라이드에서 요소 이름·텍스트를 검색해 일치하는 요소를 선택하거나 해제 |
| 사각형 범위 선택 | 드래그한 영역 안에 완전히 포함되는 요소를 각 대상 슬라이드에서 선택 |
| 이동·정렬·간격 조절 | 좌표 입력·드래그·방향키 이동, 가로·세로 정렬, 요소 사이 간격 균등 배치 |
| 텍스트 상자 맞춤 | 텍스트에 맞게 상자 높이 조절 |
| 안내선 | 가로·세로 안내선을 추가·이동·삭제하고 저장 |
| 미리보기·실행 취소·저장 | 마스터·레이아웃 장식을 포함한 미리보기, 변경 취소, 수정본 PPTX 다운로드 |

## 사용 방법

1. **PPTX 열기**로 파일을 선택합니다. 먼저 살펴보려면 **예제 슬라이드로 사용해 보기**를 누르세요.
2. 왼쪽 목록에서 **수정할 슬라이드**를 체크합니다. 문자열 검색으로 대상을 고르거나, 흐리게 표시된 비활성 미리보기를 클릭해 적용 대상에 추가할 수 있습니다.
3. 미리보기에서 요소를 클릭하거나 영역을 드래그합니다. 오른쪽 **문자열로 요소 선택**으로 반복되는 제목·텍스트를 찾을 수도 있습니다.
4. 오른쪽 편집 도구에서 **정렬, 이동, 텍스트 상자 맞춤, 안내선**을 적용합니다. 잘못 변경했다면 **마지막 변경 취소**를 누르세요.
5. **수정본 다운로드**로 결과를 저장합니다.

## 반복되는 요소를 검색해 선택하기

예제 파일에서 제목 위치를 맞추려면, 적용할 슬라이드를 체크하고 오른쪽 **요소 이름·텍스트 검색**에 제목 요소의 이름인 `Text 2`를 입력한 뒤 **일치 선택**을 누릅니다. 다른 파일에서는 해당 요소의 이름이나 실제 텍스트로 검색하세요. 검색 결과를 확인하고 정렬 또는 이동을 적용하세요.

![요소 이름 ‘Text 2’로 세 슬라이드의 제목 요소를 함께 선택한 화면](docs/images/element-search.png)

- 왼쪽 검색은 **슬라이드**를, 오른쪽 검색은 **체크한 슬라이드의 요소**를 선택합니다.
- 검색어 입력만으로 선택은 바뀌지 않습니다. **일치 선택 / Enter**로 추가하고, **일치 해제 / Shift+Enter**로 해제합니다.
- 대소문자를 구분하지 않는 문자열 검색입니다. 슬라이드 검색은 표·그룹의 본문도 포함합니다.
- 검색 결과만 슬라이드 적용 대상으로 삼으려면 먼저 왼쪽 **선택 해제**를 누른 뒤 일치 슬라이드를 선택하세요.

## 선택과 정렬 팁

- **외형 일치 선택:** 상단의 **크기·색상·레이아웃 일치**를 켜면 다음 클릭·영역 선택부터 기준 페이지와 너비·높이, 채우기·테두리·글자색, 위치·회전·그룹 내부 배치가 같은 요소만 함께 선택합니다. 기본값은 꺼짐이며 기존 선택과 문자열 검색에는 영향을 주지 않습니다. 원본 서식과 테마를 보수적으로 비교하므로, 화면상 같아 보여도 서식 표현이 다르면 제외될 수 있습니다.
- **범위 선택:** 빈 곳에서 드래그하면 사각형 안에 완전히 들어온 요소를 선택합니다. Ctrl·Shift·Cmd를 누르고 시작하면 기존 선택에 추가합니다.
- **요소 위에서 범위 선택:** 작업 공간의 **영역 선택**을 켜세요. Esc로 진행 중인 선택을 취소할 수 있습니다.
- **슬라이드 기준 정렬:** 각 슬라이드의 가장자리나 중앙에 맞춥니다. 요소 하나만 선택해도 사용할 수 있습니다.
- **선택 영역 기준 정렬:** 같은 슬라이드에서 선택한 요소들의 경계를 기준으로 맞춥니다. 슬라이드당 요소 두 개 이상이 필요합니다.
- **그룹:** 개별 내부 요소 대신 그룹을 한 단위로 선택·이동합니다.

## 로컬에서 실행

Node.js 버전은 `.node-version`을 기준으로 사용하세요.

```sh
npm ci
npm run dev
```

터미널에 표시된 주소로 접속합니다. 빌드·검증 방법은 [개발 안내](docs/development.md), 자동 배포 설정은 [Cloudflare Pages 배포](docs/deployment.md)를 참고하세요.

## 지원 범위

- `.pptx` 파일을 지원합니다. 입력 제한은 압축 파일 50 MiB, 선언된 압축 해제 크기 300 MiB, 슬라이드 120장입니다. 실행 취소는 최대 25회입니다.
- 글꼴·효과·SmartArt·일부 도형과 차트는 PowerPoint와 다르게 표시될 수 있습니다. 저장한 파일의 최종 모양은 PowerPoint에서 확인하세요.
- 슬라이드 검색은 발표자 메모, 이미지 안의 글자, 마스터·레이아웃에만 있는 텍스트를 포함하지 않습니다.

## 최근 PPTX 다시 사용하기

상단의 **최근 PPTX**에서 이 브라우저에 보관한 파일 목록을 확인하고, 사용할 파일을 직접 선택하세요. 정상적으로 연 원본 PPTX를 보관하며, 브라우저를 다시 열어도 자동으로 파일을 열지 않습니다. 같은 이름·내용의 파일은 한 항목으로 유지하고, 내용이 달라진 파일은 별도로 보관합니다.

- **삭제 / 전체 삭제**로 보관한 원본을 제거할 수 있습니다. 현재 편집 중인 문서는 유지됩니다.
- **편집 내용은 자동 저장되지 않습니다.** 수정본은 다운로드해 보관하세요. 예제 파일은 최근 목록에 자동 등록하지 않습니다.
- 파일은 서버 전송 없이 해당 브라우저의 IndexedDB에 저장됩니다. 같은 사이트·브라우저 프로필에서만 접근할 수 있습니다.
- 사이트 데이터 삭제, 비공개 모드 종료 또는 브라우저의 저장 공간 정리로 보관 파일이 삭제될 수 있습니다. 저장 공간이 부족하면 기존 파일을 자동 삭제하지 않고 보관 실패를 안내합니다.
