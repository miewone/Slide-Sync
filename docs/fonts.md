# 원본 우선 글꼴 처리

## 표시와 선택

원본 글꼴 또는 원본의 굵기·기울임을 그대로 사용할 수 없는 경우에만 `workspace-bar`에 **글꼴 확인 N** 버튼이 표시됩니다. 버튼을 누르면 화면 배치를 밀어내지 않는 플로팅 창이 열립니다. 창에는 확인이 필요한 글꼴만 표시하며, 검색·대체 선택·글꼴 파일 불러오기를 제공합니다. 바깥 클릭, 닫기 버튼 또는 Esc로 닫습니다.

글꼴 설정은 같은 원본 글꼴을 사용하는 **전체 문서의 미리보기**에 적용됩니다. 슬라이드 체크·요소 선택·XML·실행 취소 기록은 바꾸지 않습니다.

드롭다운에서 글꼴을 선택한 뒤 **적용하기**를 누릅니다. 선택만으로 적용되지 않으며, 로딩 중에는 적용 중 상태를 표시합니다. 실제 미리보기 적용이 끝난 항목에는 **글꼴 적용 완료** 표시가 붙고 확인이 필요한 개수에서 빠집니다. 모두 처리하면 버튼도 **글꼴 적용 완료**로 바뀌며, 창을 닫으면 버튼이 사라집니다. 창을 닫기 전에는 완료한 항목의 설정도 다시 바꿀 수 있습니다. 로딩에 실패한 항목은 구체적인 원인과 함께 확인 대상으로 남습니다. 같은 글꼴을 선택한 상태에서 **적용하기**를 다시 눌러 재시도할 수 있습니다.

## 원본 글꼴 선택 순서

1. 브라우저가 직접 읽을 수 있는 PPTX 내장 TTF/OTF/WOFF/WOFF2 데이터
2. PC에 설치된 동일 글꼴의 해당 굵기와 기울임
3. 배포 목록에 있는 **동일한 글꼴**
4. 원본 이름을 유지한 브라우저 대체 표시와 확인 안내

비슷한 글꼴로 자동 교체하지 않습니다. 예를 들어 맑은 고딕을 Pretendard로, 나눔스퀘어 네오를 나눔스퀘어로 자동 매칭하지 않습니다. `나눔고딕`, `NanumGothic`, `Nanum Gothic`처럼 같은 가족의 이름 표기는 매칭합니다. `Bold`, `ExtraBold` 등 이름에 포함된 굵기도 구분합니다.

PPTX의 한글·영문·복합 문자용 글꼴 지정과 `+mn-ea` 같은 테마 참조를 해석합니다. 서로 다른 글꼴이 지정된 혼합 문장은 문자 종류에 맞는 글꼴을 적용합니다.

## 직접 제공하는 방법

- **설치 글꼴 확인**: 지원하는 데스크톱 Chrome 계열에서 버튼을 눌렀을 때만 브라우저 권한을 요청합니다. 허용되면 원본과 이름·스타일이 맞는 글꼴을 다시 찾습니다.
- **글꼴 파일**: 원본에 대응하는 TTF·OTF·WOFF·WOFF2 파일을 직접 선택합니다. 파일 하나는 32 MiB 이하이며 현재 문서의 메모리에서만 사용합니다.
- **대체 선택**: 직접 선택한 경우에만 다른 무료 글꼴을 사용합니다. **원본 글꼴 우선**으로 되돌릴 수 있습니다.

제공 목록은 나눔고딕·나눔바른고딕·나눔스퀘어·나눔명조·마루부리·Pretendard·Noto Sans KR·Noto Serif KR입니다. 출처와 라이선스는 [번들 글꼴 안내](../public/fonts/README.md)에 있습니다.

## 로딩과 보존

`FontCatalogue`는 동일 글꼴 별칭과 배포 파일을 관리하고, `FontResources`는 로컬 조회·필요한 파일 로딩·시간 제한·FontFace/URL 수명을 관리합니다. `PreviewFontStyle`은 DrawingML 글꼴과 테마를 해석하고, `PreviewFonts`는 캐시·실제 렌더링·iframe의 글꼴 적용을 맞춥니다.

- 글꼴은 렌더링 및 텍스트 측정에 함께 적용합니다. 스크립트가 차단된 미리보기 iframe에도 같은 글꼴 규칙을 전달합니다.
- 글꼴 교체 시 기존 프레임과 요소 위치를 유지하고 브라우저가 텍스트를 다시 배치합니다. 원본 요소 크기를 자동 변경하지 않습니다.
- 이후 텍스트 상자 맞춤을 직접 실행하면 현재 미리보기 글꼴의 측정값으로 상자 크기를 변경합니다.
- 글꼴 파일은 사이트의 정적 자산에서만 받습니다. 사용 중인 글꼴만 요청하며, 요청과 결과를 문서 안에서 공유합니다.
- 문서 교체·종료 때 전용 FontFace와 blob URL을 해제합니다. 다운로드에는 글꼴 매핑이나 가져온 글꼴 파일을 추가하지 않습니다.
- 문서당 로드한 바이너리 글꼴은 128 MiB, 표시되는 원본 글꼴 가족은 128개로 제한합니다.

## 제한

웹폰트의 가족 이름이 같아도 설치된 버전과 글자 모양·자폭이 다를 수 있습니다. 브라우저가 설치 글꼴을 공개하지 않는 경우에는 **원본 확인 불가**로 표시합니다. 없는 글자에 대한 브라우저 대체까지 완전히 판별하는 기능은 아닙니다.

PPTX의 EOT·압축·난독화된 `.fntdata`와 TTC 컬렉션은 자동 변환하지 않습니다. 지원하지 않는 내장 형식은 원본 파일을 보존하고 설치 글꼴·동일 웹폰트·직접 선택을 사용합니다. 파일에 없는 굵기·기울임을 합성하는 경우에는 이를 표시합니다.

## 검증

`npm run test:browser -- --check-fonts`는 개발·배포·하위 경로에서 원본 우선, 명시적 대체, 파일 불러오기, 원본 XML 보존, 표시 조건, 플로팅 위치·키보드·작은 화면, 리소스 해제를 검사합니다. `tests/preview-fonts.test.js`는 별칭·스타일, 테마 해석, 설치 원본 우선, 종료 중 로딩과 배포 파일의 해시·라이선스를 검사합니다.
