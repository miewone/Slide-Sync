# Slide Sync 기능 위키

## 언어 선택

상단의 **한글 / Eng.** 버튼으로 한국어와 영어를 전환합니다. 저장한 선택이 있으면 우선 적용하고, 처음 방문하면 브라우저의 선호 언어 중 한국어·영어를 선택합니다. 둘 다 없으면 한국어를 사용합니다. 선택한 언어는 브라우저에 저장됩니다.

버튼·도움말·최근 파일 안내·상태·오류 메시지가 함께 바뀝니다. PPTX 본문과 요소 이름은 번역하지 않으며, 열린 문서·선택·편집 이력과 입력 중인 값은 유지됩니다. 화면 문구는 `src/i18n/messages.js` 한 파일에서 관리합니다.

## 빠른 시작

로컬 PPTX 파일은 브라우저 안에서 편집하며 최근 파일도 사용 중인 브라우저에 보관됩니다. Google Drive 연동을 사용하면 선택한 파일을 Google에서 읽고, 사용자가 저장할 때 Google에 변경사항을 전송합니다.

운영 빌드는 GA4 측정 ID `G-E1J2X2B0FL`로 사용자의 분석 동의 후 방문 통계를 Google Analytics 4에 전송합니다. 별도의 서버 연결은 필요하지 않으며, 개발 서버에서는 Google 태그를 로드하지 않습니다. 동의·거부는 같은 수준의 버튼으로 제공하고 거부해도 편집 기능을 사용할 수 있습니다. 선택은 180일간 브라우저에 보관하며, 하단 **쿠키 설정**에서 변경·철회할 수 있습니다. Google 태그는 동의 후 비동기로 로드되며, 자동 수집 범위는 GA4 데이터 스트림의 향상된 측정 설정에 따릅니다. PPTX 파일명·본문·검색어를 직접 전송하는 사용자 정의 이벤트는 구현하지 않았습니다.

1. **PPTX 열기**를 누르고 폴더 아이콘의 **내 컴퓨터** 또는 **Google Drive**를 선택하거나 **예제 슬라이드로 사용해 보기**를 누릅니다.
2. 왼쪽에서 수정할 슬라이드를 체크합니다. 파일을 처음 열면 모든 슬라이드가 적용 대상입니다.
3. 미리보기에서 요소를 클릭하거나 빈 곳을 드래그해 선택합니다. 오른쪽의 **문자열로 요소 선택**도 사용할 수 있습니다.
4. 오른쪽 **선택한 요소 정렬**, **요소 이동** 등 필요한 카테고리를 펼쳐 작업합니다.
5. 변경을 되돌리려면 상단의 **↶ 마지막 변경 취소**를 누릅니다.
6. **수정본 다운로드**로 결과를 새 PPTX 파일로 저장합니다.

### 예제 파일 실습 순서

**예제 슬라이드로 사용해 보기**로 여는 `예제-슬라이드.pptx`는 총 8장입니다. 각 장의 안내를 따라 실제 요소를 편집할 수 있습니다.

영어 UI에서는 본문과 도형 이름을 번역한 8장의 `example-slides.pptx`가 열립니다. 예제는 버튼을 누른 시점의 언어를 따르며, 파일을 연 뒤 UI 언어를 바꿔도 열린 슬라이드의 내용과 편집 상태는 유지됩니다. 영어 실습의 도형 검색어는 `RowCard`, `ColumnCard`, `HeightDemo`, `DemoGroup`, `DeleteDemo`입니다.

| 슬라이드 | 연습 내용 |
| --- | --- |
| 1–3 | 번호·문자열로 슬라이드 선택, 숫자·제목 동시 선택, 요소 검색, 이동과 실행 취소 |
| 4 | 가로·세로 카드 각각 3개로 여섯 방향 정렬, 두 정렬 기준, 가로·세로 간격 균등 |
| 5 | 높이가 부족한 상자와 여백이 큰 상자의 높이 맞춤, 선택한 상자·모든 상자 대상 전환 |
| 6 | 안내선 추가·위치 입력·드래그·삭제·표시, 안내선 맞추기, 좌표·상대 이동과 방향키 |
| 7 | 그룹 선택·이동, 범위 선택, 수정키로 선택 추가·해제, 영역 선택, 패널 접기·펼치기 |
| 8 | 요소 삭제와 복원, 선택한 슬라이드만 보기, 비활성 슬라이드 활성화, 다운로드·다시 열기·최근 PPTX |

4–8장은 먼저 왼쪽 **번호로 선택**에서 해당 장만 적용하고, 오른쪽 **선택 결과 → 비우기**로 이전 요소 선택을 지웁니다. 안내문에서 `가로 + 카드`처럼 표시한 검색어는 `가로카드`로 붙여 입력하세요. 안내문 자체가 검색에 함께 선택되는 것을 방지하기 위한 표기입니다. 다음 정렬 방향을 시험하기 전에는 실행 취소로 처음 배치를 복원하면 차이를 확인하기 쉽습니다.

## 화면과 선택의 두 단계

넓은 화면에서는 왼쪽–중앙, 중앙–오른쪽 사이의 경계선을 드래그해 패널 너비를 조절합니다. 마지막 너비는 해당 브라우저에 저장됩니다. 경계선에 Tab으로 초점을 둔 뒤 좌우 방향키로 조절할 수도 있으며, 두 번 클릭 또는 Home으로 해당 패널의 기본 너비를 복원합니다. 좁은 화면에서는 기존 반응형 배치를 사용합니다. 패널의 위치나 순서는 바꾸지 않습니다.

미리보기 헤더 오른쪽 상단의 **페이지 갯수 보기**는 **기본**으로 시작하며, 기존처럼 브라우저 창 너비에 맞춰 자동 배치합니다. `2×2`, `4×4`를 누르거나 **가로 입력칸 × 세로 입력칸**에 각각 1–8을 입력해 배치를 바꿀 수 있습니다. 세로 칸 수에 맞춰 미리보기 높이를 조정하며, 작은 화면에서는 최소 카드 높이를 유지합니다. 전체 슬라이드는 아래로 계속 스크롤합니다. 보기 변경은 적용 대상·요소 선택·편집 내용·실행 취소 기록에 영향을 주지 않습니다.

| 영역 | 역할 |
| --- | --- |
| 상단 | PPTX 열기, 수정본 다운로드 |
| 왼쪽 슬라이드 목록 | 작업을 적용할 슬라이드를 체크하고 번호·문자열로 범위 지정 |
| 가운데 미리보기 | 요소 클릭·범위 선택·드래그 이동, 안내선 확인 |
| 오른쪽 편집 패널 | 요소 검색, 정렬, 이동, 안내선, 텍스트 상자 맞춤, 선택 결과 |
| 아래 상태 표시줄 | 처리 결과와 슬라이드 크기 확인 |

**슬라이드 적용 대상**은 왼쪽에서 체크한 슬라이드입니다. **요소 선택**은 그 슬라이드 안에서 편집할 도형·텍스트·이미지·표·그룹입니다.

왼쪽 슬라이드 목록에서 요소가 선택된 슬라이드는 각 컨테이너 오른쪽 위에 **N개 선택**을 표시합니다.

가운데 미리보기의 슬라이드에 마우스를 올리면 왼쪽 목록의 해당 슬라이드를 보라색 펄스 애니메이션으로 강조합니다. 마우스가 벗어나면 강조가 해제되며, 동작 줄이기 설정에서는 애니메이션 없이 보라색으로 표시합니다.

예를 들어 슬라이드 1·3·5를 체크한 다음 제목 요소를 선택하면, 해당 세 슬라이드의 선택된 제목에 이동·정렬을 적용합니다. 슬라이드 체크만으로 모든 요소가 선택되지는 않습니다.

체크를 해제한 슬라이드의 요소 선택은 기억됩니다. 다시 체크하면 기억된 선택이 돌아옵니다. 공통 안내선은 별도로, 체크 범위와 관계없이 전체 슬라이드에 적용됩니다.

## 파일 열기와 미리보기

한글/영어 선택 왼쪽의 **작업 로그** 아이콘에 새 기록 개수가 표시됩니다. 파일 열기·글꼴 적용·편집·다운로드 결과가 쌓이면 숫자 배지가 짧게 강조되며, 클릭하면 시간과 성공·경고·실패 내용을 확인할 수 있습니다. 최근 200개를 현재 탭에서 보관하고 **로그 비우기**로 초기화합니다. [공통 로그 모듈과 사용법](activity-log.md)

원본 글꼴을 그대로 사용할 수 없으면 상단 작업 도구에 **글꼴 확인** 버튼이 표시됩니다. 클릭하면 플로팅 창에서 필요한 글꼴만 확인하고 설치 글꼴 조회·파일 선택·대체 글꼴 지정을 할 수 있습니다. 원본과 동일한 글꼴을 우선 사용하며, 다른 글꼴은 직접 선택할 때만 전체 문서의 미리보기에 적용합니다. 원본 PPTX 글꼴과 실행 취소 기록은 유지합니다. [글꼴 처리 상세](fonts.md)

글꼴을 적용하면 남은 확인 개수가 줄어듭니다. 전부 처리하면 **글꼴 적용 완료**로 바뀌고, 창을 닫을 때 확인 버튼도 사라집니다.

표는 열 너비와 행 높이를 기준으로 미리보기와 선택 영역을 구성하며, 병합 셀의 열 비율을 유지합니다. 같은 유형의 제목 상자가 여러 개 있어도 레이아웃의 자리표시자 번호로 서식을 구분합니다. 이 미리보기 보정은 원본 PPTX의 표 크기나 텍스트 서식을 변경하지 않습니다.

### Google Drive에서 열기와 저장

상단 **PPTX 열기**는 파일 위치 선택 창을 표시합니다. 폴더 아이콘의 **내 컴퓨터**를 누르면 운영체제 파일 탐색기가 열리고, **Google Drive** 아이콘을 누르면 연결이 유효하면 바로 파일 선택기를 엽니다. 연결이 필요하면 **Google 연결** 후 자동으로 파일 선택기를 엽니다. 파일을 선택하면 양쪽 노란 폴더 사이로 종이가 접히며 날아가는 Windows 스타일 로딩 애니메이션을 표시하고, 파일 열기가 완료되거나 실패하면 닫습니다. 아이콘을 누르면 “현재는 Google Slides 선택 시 편집이 어렵습니다.”라는 안내가 표시됩니다. 닫기 또는 Esc로 선택을 취소할 수 있습니다.

상단 **PPTX 열기 → Google Drive**에서 PPTX 또는 Google Slides 문서를 선택합니다. Google Drive 카드 오른쪽 아래 **톱니바퀴**에서 연결·저장 메뉴와 **내 Google API 설정**을 열 수 있습니다. 톱니바퀴로 연 창에서 **닫기** 또는 Esc를 누르면 파일 위치 선택 팝업으로 돌아갑니다. 처음에는 **내 Google API 설정**에서 사용자가 자신의 API 키·OAuth 클라이언트 ID·프로젝트 번호를 입력합니다. 같은 Google Cloud 프로젝트의 값을 사용하며, 설정은 이 브라우저의 IndexedDB에 저장됩니다. 클라이언트 Secret은 사용하지 않습니다. 저장한 설정을 수정·삭제할 수 있습니다. 설정 창의 **gcloud로 설정하기**를 펼치면 API 활성화·키 생성·프로젝트 번호 조회 명령을 복사할 수 있습니다. [gcloud 가이드](google-drive-gcloud.md) [설정 방법](deployment.md#google-drive--google-slides-연동)

- **PPTX**는 기존 편집기에서 작업합니다. **PPTX 열기 → Google Drive 톱니바퀴 → 현재 PPTX 저장**으로 원본 또는 새 파일을 선택합니다. 로컬 PPTX도 새 파일로 Drive에 저장할 수 있습니다. 로컬 파일·예제·최근 목록의 보관한 사본을 열면 이전 Drive 원본과의 연결은 해제됩니다.
- **Google Slides**는 전용 화면에서 네이티브 객체를 직접 편집합니다. 체크한 슬라이드의 요소를 이름·문자열로 선택하고 이동, 정렬, 간격 균등, 삭제할 수 있습니다. 그룹은 한 객체로 취급하며 하위 구조를 유지합니다. 위치는 cm 단위이고 절대 이동은 선택 영역의 좌상단 기준입니다.
- **저장** 창은 매번 원본/새 파일을 선택하게 합니다. 기본 선택은 새 파일이며, 이름과 폴더를 지정합니다. PPTX는 PPTX로, Google Slides는 Google Slides로 저장합니다. Slides의 새 파일 저장은 원본을 네이티브 복사한 뒤 수정하므로 변환을 거치지 않습니다.
- Slides의 **Google에 저장된 모습**은 서버의 저장본 이미지이며, **저장 전 편집 배치**는 요소의 위치·크기와 변경 표시를 보여줍니다. 편집 배치는 원본 서식의 실시간 렌더링이 아닙니다. 저장 후 서버 미리보기를 다시 조회합니다. 안내선, 글꼴 대체 및 텍스트 높이 맞춤은 현재 Slides 전용 화면에서 지원하지 않습니다.
- 저장 전에는 실행 취소·다시 실행을 사용할 수 있습니다. 저장 성공 시 실행 취소 기록을 초기화합니다. 저장하지 않은 편집은 현재 탭에만 남으며, 닫을 때 변경을 버릴지 확인합니다.
- Google 연결은 접근 토큰의 유효기간 동안 같은 브라우저에서 복원됩니다. 새로고침해도 다시 연결할 필요가 없으며, 만료 후에는 **Google 연결**을 눌러야 합니다. **연결 해제**는 브라우저에 저장된 토큰을 삭제합니다.
- 다른 사용자가 원본을 변경하면 저장을 중단합니다. 오류 시 편집 내용은 유지합니다. 연결이 만료되면 **Google 연결**로 다시 인증합니다. 읽기 전용 문서는 원본 저장을 선택할 수 없습니다.

### 파일 열기

첫 화면에서 최근 보관한 PPTX가 없으면 **예제 슬라이드 사용해보기**를 중앙에 강조합니다. 최근 파일 목록 확인이 끝난 뒤 표시하며, 버튼이 부드럽게 커졌다 돌아오는 효과를 3회 반복해 강조합니다. 동작 줄이기 설정에서는 효과를 끕니다. 버튼을 눌러야 예제를 엽니다. 내 PPTX 열기와 파일 끌어 놓기도 그대로 사용할 수 있습니다.

- **PPTX 열기** 또는 빈 화면의 **파일 선택**으로 `.pptx` 파일을 엽니다.
- 파일을 앱 화면으로 끌어 놓아도 열 수 있습니다.
- 예제 파일은 설치나 준비 없이 **예제 슬라이드로 사용해 보기**로 확인합니다.
- 파일 처리는 브라우저 안에서 이루어집니다. PPTX는 서버에 업로드하지 않습니다.

새 파일을 열면 슬라이드 체크는 전체 선택으로 시작하고, 요소 선택·검색어·실행 취소 기록은 초기화됩니다. 가져오기에 실패하면 이전에 열었던 파일과 검색 상태를 유지합니다.

### 미리보기

- 화면 근처 슬라이드부터 표시하고, 다른 슬라이드도 순차적으로 준비합니다.
- 슬라이드 XML과 참조 이미지·레이아웃·테마, 문서 기본값을 SHA-256으로 비교합니다. 해시가 같으면 브라우저에 보관한 미리보기를 즉시 재사용하고, 다른 슬라이드만 새로 렌더링합니다. 브라우저를 닫았다 열거나 파일명을 바꿔도 재사용할 수 있습니다.
- 편집한 PPTX를 다운로드하면 해당 시점의 미리보기를 백그라운드에서 보관합니다. 보관이 끝난 뒤 해당 파일을 다시 열면 재사용합니다. 앱 렌더링 코드가 바뀌면 캐시를 새로 만들며, 저장 공간이 부족하거나 저장이 차단되어도 기존 렌더링과 다운로드는 동작합니다.
- 미리보기 캐시는 최대 32 MiB·240장(슬라이드당 4 MiB)이며 오래 사용하지 않은 항목부터 비웁니다. 최근 파일을 개별 삭제하거나 전체 삭제하면 공유 미리보기 캐시도 비웁니다. 간이 미리보기는 저장하지 않습니다.
- 전체 미리보기 준비가 끝나면 편집 도구가 활성화됩니다. 최근 파일 원본·미리보기 보관 완료는 기다리지 않으며, 보관 중에도 이동·실행 취소·다운로드·다른 파일 열기가 가능합니다. 화면 밖 슬라이드도 적용 대상에 포함할 수 있습니다.
- 마스터·레이아웃 장식 도형과 테마 색상을 가능한 범위에서 표시합니다. 마스터 그래픽 숨김 설정도 반영합니다.
- 미리보기 슬라이드에 마우스를 올리면 왼쪽의 해당 슬라이드 항목을 강조하고, 목록 밖에 있으면 목록을 스크롤해 보여 줍니다. 마우스가 벗어나면 강조를 해제하며, 호버만으로 체크나 요소 선택은 바뀌지 않습니다.
- **선택한 슬라이드만 보기**를 켜면 체크한 슬라이드만 미리보기에 표시합니다. 이 옵션은 체크 상태를 바꾸지 않습니다.
- 렌더링에 실패한 슬라이드는 **간이 미리보기**로 표시될 수 있습니다.
- 파일에 기본 텍스트 스타일(`p:defaultTextStyle`)이 없어도 미리보기를 표시하며, 다운로드할 때 원본에 기본 스타일을 추가하지 않습니다.
- XML을 읽지 못하면 오류 메시지에 실패한 내부 파일 경로와 파서의 상세 원인을 표시합니다.
- XML 맨 앞의 BOM과 `ï»¿`로 잘못 해석된 BOM은 읽을 때 제거해 브라우저별 XML 파싱 차이를 방지하며, 원본 패키지는 보존합니다.
- UTF-8·UTF-16 LE/BE와 브라우저가 지원하는 명시적 인코딩 선언을 읽습니다. 잘못된 바이트나 선언 충돌은 내부 파일 경로와 함께 알립니다.
- 편집하지 않은 XML은 원본 바이트를 보존하고, 편집한 XML은 UTF-8 선언과 바이트를 맞춰 저장합니다. [XML 호환성 및 알려진 제한](xml-compatibility.md)을 참고하세요.

하단의 **최근 파일·미리보기 보관 중…** 표시는 브라우저 저장 작업이 남아 있음을 뜻합니다. 표시가 사라지기 전에 새로고침하거나 창을 닫으면 보관이 완료되지 않을 수 있습니다. 로컬 PPTX와 Drive PPTX는 열었던 원본을 브라우저에 보관하며, 편집 결과는 **수정본 다운로드**로 저장합니다. 최근 파일 목록의 선택·삭제는 저장 순서를 지키기 위해 보관이 끝난 뒤 사용할 수 있고, 목록 창은 기다리는 동안 닫을 수 있습니다.

## 슬라이드 적용 대상 지정

상단 옵션은 버튼형 체크박스이며, 켜진 옵션은 파란 배경과 체크 표시로 구분합니다. 체크박스와 라벨 사이의 `?`에서 도움말을 확인하고, Tab·Space로도 조작할 수 있습니다.

**선택한 요소가 있는 슬라이드만 보기**를 켜면 현재 선택 요소가 있는 슬라이드만 표시합니다. 선택·해제·삭제·실행 취소 시 자동으로 갱신하며, 적용 대상이나 선택 자체를 바꾸지는 않습니다. **선택한 슬라이드만 보기**와 함께 켜면 두 조건을 모두 적용합니다. 선택 요소가 없어 화면이 비면 보기 필터를 끄고 다시 선택하세요.

| 방법 | 동작 |
| --- | --- |
| 왼쪽 목록의 체크박스 | 해당 슬라이드를 적용 대상에 포함하거나 해제 |
| 미리보기 카드 제목 옆 체크박스 | 왼쪽 목록과 같은 체크 상태를 변경 |
| 비활성 미리보기 클릭 | 클릭한 슬라이드를 기존 적용 대상에 추가 |
| **전체 선택** | 모든 슬라이드를 적용 대상으로 지정 |
| **선택 해제** | 모든 슬라이드의 적용 대상 체크를 해제 |
| **번호로 선택 → 적용** | 입력한 번호 목록으로 적용 대상을 교체 |

번호는 `1, 3-5`처럼 입력합니다. 이 예시는 1·3·4·5번 슬라이드를 선택합니다. 슬라이드 번호는 1부터 시작하며 실제 슬라이드 수 안에서 지정해야 합니다. 번호 입력 칸에서는 Enter로도 적용할 수 있습니다.

적용 대상 체크 해제는 슬라이드나 슬라이드 안의 요소를 삭제하지 않습니다.

체크 해제되어 흐리게 표시된 슬라이드는 미리보기를 클릭하면 활성화됩니다. 첫 클릭은 활성화만 수행하고, 다른 슬라이드의 체크와 요소 선택을 유지하며 해당 슬라이드의 기억된 요소 선택을 복원합니다. 이후 클릭·드래그부터 기존 요소 선택·이동을 사용할 수 있습니다. 미리보기에 키보드 포커스를 둔 뒤 Enter 또는 Space로도 활성화할 수 있습니다. 파일을 준비하는 동안에는 활성화되지 않습니다.

## 문자열 검색

### 왼쪽: 슬라이드 검색

**문자열로 선택**에서 제목·본문을 검색합니다. 목록에 표시되는 짧은 제목뿐 아니라 긴 본문, 표와 그룹 안의 텍스트도 검색합니다.

1. 검색어를 입력합니다.
2. 일치 개수와 각 목록 행의 **일치** 표시를 확인합니다.
3. **일치 선택**으로 검색 결과를 기존 적용 대상에 추가합니다.
4. **일치 해제**로 검색 결과에 해당하는 슬라이드의 체크만 해제합니다.

**검색 결과만 적용 대상으로 삼으려면** 왼쪽 **선택 해제**를 누른 다음 검색하여 **일치 선택**을 누르세요. 일치 선택은 기존 체크를 유지하며 추가하는 방식입니다.

### 오른쪽: 요소 검색

**문자열로 요소 선택**을 펼치고 **요소 이름·텍스트 검색**에 입력합니다. 현재 체크한 슬라이드의 편집 가능한 요소만 검색합니다.

입력창에 포커스를 두면 왼쪽에 **요소 이름 목록**이 표시됩니다. 현재 체크한 슬라이드에서 편집 가능한 최상위 요소의 이름을 모아 보여주며, 같은 이름은 개수와 슬라이드 번호를 함께 표시합니다. 그룹은 그룹 이름으로 표시합니다.

- 목록의 이름을 누르면 검색창에 입력하고 **일치 요소를 기존 선택에 추가**합니다. 기존 문자열 검색과 동일하게 이름·본문의 부분 일치를 사용합니다.
- 입력창에서 ↓를 누르면 목록으로 이동합니다. 목록은 방향키·Tab으로 탐색하고 Enter로 이름을 선택할 수 있습니다.
- Esc, 목록 바깥 클릭·포커스 이동, 검색 카테고리 접기로 목록을 닫습니다. Esc로 목록을 닫을 때 요소 선택은 유지합니다.
- 체크 범위 변경, 요소 삭제·실행 취소, 파일 교체에 따라 이름 목록도 갱신됩니다. 이름이 많으면 **더 보기**로 100개씩 추가 표시합니다.
- 화면이 좁으면 목록은 입력창 아래에 표시됩니다.

- 요소 이름과 전체 텍스트를 검색합니다. 이미지처럼 본문이 없는 요소도 이름으로 찾을 수 있습니다.
- 일치 요소 수, 해당 슬라이드 수, 그중 선택된 요소 수를 표시합니다.
- **일치 선택**은 기존 요소 선택에 추가하고, **일치 해제**는 일치하는 요소만 선택 해제합니다.
- 표는 하나의 요소로 선택합니다. 그룹 안의 텍스트나 이름이 일치하면 그룹 전체를 선택합니다.
- 숨김 요소, 숨겨진 그룹 자식의 텍스트, 위치를 해석하지 못한 최상위 요소는 검색·선택 대상에서 제외합니다.

**검색 결과 요소만 선택하려면** 오른쪽 **선택 결과**를 펼쳐 **비우기**를 누른 뒤 검색 결과를 선택합니다. 왼쪽 슬라이드 체크는 유지됩니다.

### 두 검색의 공통 규칙

| 항목 | 규칙 |
| --- | --- |
| 적용 시점 | 검색어 입력만으로 선택은 바뀌지 않으며 버튼이나 Enter로 확정 |
| 대소문자 | 영문 대소문자를 구분하지 않음 |
| 공백·글자 표현 | 연속 공백과 유니코드 표현 차이를 정규화하여 검색 |
| 서식이 나뉜 단어 | 같은 단락 안의 연속된 텍스트 조각을 이어서 검색 |
| 특수문자 | `.*`, `[ ]` 등을 입력한 글자 그대로 검색 |
| 빈 검색어·일치 없음 | 선택·해제 작업을 실행하지 않음 |
| Enter | 일치 항목을 선택에 추가 |
| Shift+Enter | 일치 항목을 선택 해제 |
| 한글 조합 중 Enter | 조합을 확정하는 Enter를 선택 명령으로 처리하지 않음 |

발표자 메모, 이미지 안의 글자, 마스터·레이아웃에만 있는 텍스트, 별도 차트 데이터는 검색 대상에 포함하지 않습니다. 두 검색어는 독립적이며, 새 파일을 열면 모두 초기화됩니다.

## 클릭과 드래그로 요소 선택

### 클릭 선택

- 미리보기에서 클릭한 위치의 가장 앞 요소를 각 적용 대상 슬라이드에서 선택합니다.
- Ctrl·Shift·Cmd를 누르고 클릭하면 선택을 추가하거나 해당 요소의 선택을 해제합니다.
- 그룹은 내부 요소를 따로 편집하지 않고 한 단위로 선택·이동합니다.
- **선택한 요소들을 감싸는 박스의 왼쪽 위**에 요소 이름이 표시됩니다. 여러 요소를 선택하면 첫 요소 이름과 추가 개수를 표시하고, 미리보기에 마우스를 올리면 전체 이름을 확인할 수 있습니다. 이름 표시는 이동·정렬·실행 취소에 따라 선택 박스를 따라가며, 위쪽 여백이 부족하면 미리보기 안쪽에 표시합니다. PPTX에는 저장되지 않습니다.
- 왼쪽 슬라이드 목록 아래의 **선택 결과**에서 슬라이드별 선택 요소를 카드로 확인합니다. 카드마다 슬라이드 번호와 선택 개수를 표시하며, 선택이 없는 슬라이드는 회색으로 구분합니다. 목록에서도 적용/제외 상태와 선택한 요소 수를 확인할 수 있습니다.
- **비우기** 또는 드래그 중이 아닐 때 Esc로 요소 선택을 해제합니다.

### 사각형 범위 선택

1. 미리보기의 **빈 곳에서 드래그**합니다.
2. 같은 사각형 범위를 체크한 슬라이드에 적용합니다.
3. 사각형 안에 **완전히 포함된 요소**를 마우스를 놓을 때 선택합니다. 일부만 걸친 요소는 제외합니다.

오른쪽 아래에서 왼쪽 위로 그리는 등 역방향 드래그도 가능합니다. 회전한 요소는 회전된 경계 전체가 포함돼야 하며, 그룹은 그룹의 경계를 기준으로 판단합니다.

Ctrl·Shift·Cmd를 누른 채 드래그를 **시작**하면 기존 선택에 추가합니다. 일반 범위 선택은 적용 대상 슬라이드의 요소 선택을 교체하며, 체크하지 않은 슬라이드의 기억된 선택은 유지합니다.

### 요소 위에서 범위를 그리고 싶을 때

배경 도형이 슬라이드를 덮고 있거나 요소 위에서 선택을 시작하려면 가운데 위쪽의 **영역 선택**을 켭니다. 이 상태에서는 요소 위에서도 사각형을 그립니다. 요소를 드래그해 이동하려면 이 옵션을 끄세요.

Esc, 포인터 취소, 창 포커스 해제 또는 적용 대상 변경으로 범위 드래그를 취소하면 이전 선택을 유지합니다. 범위 선택 자체는 PPTX 내용이나 실행 취소 기록을 바꾸지 않습니다.

## 요소 삭제

요소를 클릭하거나 범위·검색으로 선택한 뒤 오른쪽 **선택 요소 삭제**를 누릅니다. Delete 또는 Backspace도 사용할 수 있습니다.

- 체크한 적용 대상 슬라이드의 선택 요소만 삭제합니다. 체크하지 않은 슬라이드의 요소와 선택 기억은 유지됩니다.
- 그룹은 내부 요소를 포함해 한 단위로 삭제됩니다. 배경과 마스터 요소는 삭제 대상이 아닙니다.
- **마지막 변경 취소 / Ctrl·Cmd+Z**로 삭제한 요소와 선택 상태를 복원합니다. 여러 슬라이드의 동시 삭제도 한 번에 되돌립니다.
- 입력란에서 글자를 지우거나 한글을 조합하는 중에는 요소 삭제가 실행되지 않습니다.
- 삭제는 현재 문서의 원본 XML과 미리보기에 반영됩니다. 결과를 보관하려면 **수정본 다운로드**를 사용하세요.

## 요소 이동

오른쪽 **요소 이동**을 펼쳐 좌표를 입력하거나, 선택한 요소를 직접 드래그합니다. 좌표 단위는 **cm**이며 왼쪽 위를 기준으로 오른쪽이 X의 양수, 아래쪽이 Y의 양수입니다.

| 이동 방식 | 입력값의 의미 | 예시 |
| --- | --- | --- |
| **모두 같은 위치로 맞추기** | 지정한 X/Y 위치로 이동 | X `3`, Y `2`로 입력하면 각 슬라이드의 선택을 같은 위치에 맞춤 |
| **같은 거리만큼 이동하기** | 현재 위치에서 이동할 거리 | X `1`, Y `-0.5`로 입력하면 오른쪽 1cm, 위쪽 0.5cm 이동 |

여러 요소를 선택했다면 내부 간격을 유지하며 함께 이동합니다. **모두 같은 위치로 맞추기**에서는 각 슬라이드의 선택 영역 왼쪽 위를 입력한 위치에 맞춥니다.

### 드래그와 미세 이동

- **영역 선택**을 끈 상태에서 선택된 요소를 드래그하면 선택한 요소들이 함께 이동합니다.
- Shift를 누르면 가로 또는 세로 한 방향으로 고정합니다.
- 이동 중에는 위치와 크기, 이동 예정 위치가 표시됩니다. 마우스를 놓을 때 변경을 확정합니다.
- Esc나 포인터 취소로 진행 중인 이동을 취소할 수 있습니다.
- 미리보기에 포커스를 두고 방향키로 미세 이동할 수 있습니다. 이동량은 [단축키](#단축키)를 참고하세요.

이동은 요소의 크기와 회전을 유지합니다.

## 정렬과 간격 균등

오른쪽 **선택한 요소 정렬**을 펼치고 **정렬 기준**을 선택한 뒤 원하는 버튼을 누릅니다.

| 정렬 기준 | 최소 선택 수 | 기준 영역 |
| --- | --- | --- |
| **선택한 요소들의 영역** | 같은 슬라이드에서 2개 이상 | 그 슬라이드에서 선택한 요소들을 감싸는 영역 |
| **슬라이드 전체** | 같은 슬라이드에서 1개 이상 | 슬라이드 전체 영역 |

조건을 충족한 체크 슬라이드의 선택 요소에 적용합니다. 예를 들어 세 슬라이드에서 요소를 하나씩 선택했다면 **슬라이드 전체** 기준으로 정렬할 수 있습니다.

| 방향 | 버튼 | 결과 |
| --- | --- | --- |
| 가로 | **왼쪽** | 왼쪽 경계를 맞춤 |
| 가로 | **가운데** | 가로 중심을 맞춤 |
| 가로 | **오른쪽** | 오른쪽 경계를 맞춤 |
| 세로 | **상단** | 위쪽 경계를 맞춤 |
| 세로 | **중단** | 세로 중심을 맞춤 |
| 세로 | **하단** | 아래쪽 경계를 맞춤 |

가로 정렬은 X만, 세로 정렬은 Y만 변경합니다. 요소의 크기와 회전은 유지하며 회전된 요소의 실제 경계를 기준으로 계산합니다. 선택하지 않은 요소는 이동하지 않습니다.

### 간격 균등

같은 패널의 **간격 균등**을 펼쳐 **가로 간격 균등** 또는 **세로 간격 균등**을 누릅니다.

- 같은 슬라이드에서 요소를 **3개 이상** 선택해야 합니다.
- 양 끝 요소의 위치를 유지하고 요소의 경계 사이 간격을 같게 맞춥니다.
- 크기가 다른 요소도 경계 사이 간격을 기준으로 배치합니다.

## 텍스트 상자 높이 맞춤

오른쪽 **텍스트 상자 맞춤**을 펼칩니다.

1. **맞춤 대상**에서 **적용 슬라이드의 모든 텍스트 상자** 또는 **현재 선택한 텍스트 상자**를 고릅니다.
2. 대상 텍스트 상자 수를 확인합니다.
3. **텍스트에 맞게 높이 조정**을 누릅니다.

지정된 글자 크기와 상자 너비·위치를 유지하고, 높이를 내용에 맞게 늘리거나 줄입니다. 제목 상자도 조건을 충족하면 포함합니다. 화면 밖 슬라이드도 측정 대상에 포함됩니다.

**텍스트에 맞게 가로 조정**은 **가로 맞춤 대상**에서 적용 슬라이드의 **전체 / 선택한 텍스트 상자**를 선택할 수 있습니다. **투명·흰색 배경만**을 켜면 조건에 맞는 상자만 조정합니다. 단색·투명 채우기와 상속·테마 색상을 판별하며, 그라데이션·이미지·판별할 수 없는 색상은 제외합니다. 너비만 조정하며 위치·높이·글자 크기를 유지합니다. **가로 맞춤 시 자동 줄바꿈 풀기**는 기본적으로 꺼져 있어 현재 줄바꿈을 유지하면서 여분의 너비를 줄입니다. 옵션을 켜면 자동 줄바꿈을 풀고 직접 입력한 줄바꿈은 유지하여 가장 긴 줄과 내부 여백에 맞춥니다. 실행 취소·다시 실행과 PPTX 저장을 지원합니다.

그룹 내부 텍스트, 세로쓰기, 텍스트 자체의 회전, 여러 단으로 구성된 텍스트 등 일부 형식은 제외됩니다. 측정할 수 없는 항목은 건너뛰며 상태 메시지로 알려 줍니다. 사용 중인 글꼴과 PowerPoint의 배치 방식에 따라 결과가 달라질 수 있습니다.

## 안내선

오른쪽 **안내선**을 펼쳐 사용합니다.

| 설정·버튼 | 역할 |
| --- | --- |
| **안내선 표시** | 미리보기에서 안내선 표시 또는 숨김 |
| **이동할 때 안내선에 맞추기** | 요소 드래그 시 경계나 중심을 가까운 안내선에 맞춤 |
| **안내선을 드래그하여 편집** | 공통 안내선을 마우스로 움직일 수 있게 함 |
| **+ 가로 안내선** | 위·아래 위치를 맞출 가로 공통 안내선 추가 |
| **+ 세로 안내선** | 왼쪽·오른쪽 위치를 맞출 세로 공통 안내선 추가 |
| **안내선 선택 → 위치 → 적용** | 선택한 공통 안내선의 위치를 숫자로 변경 |
| **삭제** | 선택한 공통 안내선 삭제 |

가로 안내선 위치는 위에서부터, 세로 안내선 위치는 왼쪽에서부터 cm로 입력합니다. 안내선 목록에는 현재 기준 슬라이드에 적용되는 공통·상속 안내선이 표시됩니다.

**공통 안내선은 체크한 슬라이드 범위와 관계없이 전체 슬라이드에 적용되며 수정본 PPTX에도 저장됩니다.** 기존 마스터·레이아웃 안내선은 표시와 맞추기에 사용할 수 있으며 위치 수정·삭제는 읽기 전용입니다.

안내선 맞추기는 요소 드래그에 적용됩니다. Alt를 누른 채 드래그하면 잠시 맞추기를 해제합니다. 숫자 입력·방향키·정렬 명령은 지정한 값과 기준에 따라 동작합니다. **안내선 표시**를 끄면 드래그 맞추기도 적용하지 않습니다.

## 편집 카테고리 접기와 펼치기

오른쪽 카테고리 제목을 클릭하거나, 제목에 키보드 포커스를 둔 뒤 Enter·Space를 누릅니다.

| 카테고리 | 처음 표시되는 상태 |
| --- | --- |
| 문자열로 요소 선택 | 펼침 |
| 선택한 요소 정렬 | 펼침 |
| 요소 이동 | 펼침 |
| 안내선 | 접힘 |
| 텍스트 상자 맞춤 | 접힘 |
| 선택 결과 | 접힘 |

각 카테고리는 독립적으로 조작합니다. 접어도 입력값·검색어·선택 상태는 유지됩니다. 같은 화면에서 파일을 바꿔도 카테고리의 접힘 상태는 유지되며, 새로고침하면 기본 상태로 시작합니다. 선택 요약과 **↶ 마지막 변경 취소**는 카테고리 밖 상단에 있습니다.

## 실행 취소와 저장

### 실행 취소

- 선택 요약 아래 한 줄의 작은 아이콘 버튼으로 삭제, 실행 취소(↶), 다시 실행(↷)을 사용할 수 있습니다.
- **↶** 또는 Ctrl/Cmd+Z로 이동·정렬·삭제·텍스트 서식·텍스트 높이·안내선 변경을 되돌립니다. **↷** 또는 Ctrl/Cmd+Y로 다시 실행합니다.
- 한 번에 여러 슬라이드를 변경한 작업은 한 번의 실행 취소로 복원합니다.
- 방향키를 계속 누른 이동은 하나의 연속 작업으로 묶습니다.
- 최대 **25회**의 변경 기록을 유지합니다.
- 슬라이드 체크, 요소 선택, 검색, 표시 옵션, 카테고리 접기는 편집 실행 취소 기록을 만들지 않습니다.

### 저장

**수정본 다운로드**를 누르면 `원래파일명-edited.pptx` 형식의 수정본을 다운로드합니다. 체크를 해제한 슬라이드도 파일에 포함되며, 선택한 슬라이드만 별도 추출하는 동작은 아닙니다.

작업은 열린 브라우저 화면에 보관됩니다. 새 파일을 열거나 새로고침·종료하기 전에 필요한 수정본을 다운로드하세요. 저장한 파일을 다시 열어 계속 편집할 수 있습니다.

## 단축키

Mac에서는 아래 Ctrl 기능에 Cmd(⌘)도 사용할 수 있습니다. 방향키·전체 요소 선택은 미리보기를 클릭해 포커스를 둔 상태에서 사용합니다. 입력창에 포커스가 있으면 입력창의 편집 동작을 따릅니다.

| 키·동작 | 기능 |
| --- | --- |
| Ctrl / Shift / Cmd + 클릭 | 요소 선택 추가·해제 |
| 빈 곳에서 드래그 | 사각형 범위 선택 |
| Ctrl / Shift / Cmd를 누르고 범위 드래그 시작 | 기존 요소 선택에 추가 |
| Shift + 요소 드래그 | 가로·세로 이동 방향 고정 |
| Alt + 요소 드래그 | 안내선 맞추기 일시 해제 |
| 방향키 | 0.1cm 이동 |
| Shift + 방향키 | 1cm 이동 |
| Ctrl / Cmd + 방향키 | 0.01cm 이동 |
| Ctrl / Cmd + A | 적용 대상 슬라이드의 편집 가능한 요소 전체 선택 |
| Delete / Backspace | 선택 요소 삭제 (입력란 편집 중 제외) |
| Ctrl / Cmd + Z | 마지막 편집 변경 취소 |
| Ctrl / Cmd + Y | 취소한 편집 다시 실행 |
| Esc | 진행 중인 드래그 취소, 드래그 중이 아니면 요소 선택 해제 |
| 검색창에서 Enter | 일치 항목 선택 추가 |
| 검색창에서 Shift+Enter | 일치 항목 선택 해제 |
| 번호 입력창에서 Enter | 입력한 슬라이드 번호 적용 |
| 비활성 미리보기에서 Enter / Space | 해당 슬라이드를 적용 대상에 추가 |
| 카테고리 제목에서 Enter / Space | 해당 카테고리 접기·펼치기 |

## 자주 쓰는 작업 예시

### 여러 슬라이드의 제목을 가운데 맞추기

1. 예제 파일을 엽니다.
2. 적용할 슬라이드를 체크합니다.
3. 오른쪽 요소 검색에 예제 제목 요소 이름인 `Text 2`를 입력하고 **일치 선택**을 누릅니다.
4. **선택한 요소 정렬**에서 기준을 **슬라이드 전체**로 고릅니다.
5. **가로 정렬 → 가운데**를 누릅니다.
6. 미리보기를 확인하고 수정본을 다운로드합니다.

다른 PPTX에서는 실제 제목 텍스트나 그 파일의 요소 이름을 검색하세요. 요소 이름은 파일마다 다를 수 있습니다.

### 특정 문구가 있는 슬라이드만 수정하기

1. 왼쪽 **선택 해제**로 적용 대상을 비웁니다.
2. 왼쪽 문자열 검색에 `매출` 등 필요한 문구를 입력합니다.
3. **일치 선택**을 누르고 필요하면 **선택한 슬라이드만 보기**를 켭니다.
4. 해당 슬라이드의 요소를 검색하거나 범위로 선택한 뒤 편집합니다.

### 기존 선택에서 특정 요소만 빼기

1. 범위 드래그 등으로 여러 요소를 선택합니다.
2. 오른쪽 요소 검색에서 제외할 이름이나 텍스트를 찾습니다.
3. **일치 해제**를 누릅니다. 다른 요소 선택과 슬라이드 체크는 유지됩니다.

### 카드나 텍스트 상자를 같은 간격으로 배치하기

1. 각 적용 대상 슬라이드에서 요소를 3개 이상 선택합니다.
2. 필요하면 **세로 정렬 → 상단**으로 위쪽 경계를 맞춥니다.
3. **간격 균등 → 가로 간격 균등**을 누릅니다.
4. 양 끝 요소가 유지되고 중간 요소들의 간격이 맞춰졌는지 확인합니다.

## 성능 측정 결과

10장·100장 문서의 렌더링, 전체 선택·이동·정렬·높이 맞춤·삭제·실행 취소와 PPTX 출력 시간을 [작업별 실측 문서](workflow-performance.md)에 정리했습니다. 각 3회의 중앙값·최소·최대, 실제 처리 요소 수, 측정 환경과 원본 JSON을 함께 제공합니다. 합성 문서 관측값이며 실제 PPTX의 이미지·효과·폰트 구성에 따라 달라집니다.

| 상황 | 확인할 내용 |
| --- | --- |

| 요소 검색 결과가 없음 | 적용할 슬라이드가 체크돼 있는지, 요소 이름·실제 텍스트가 맞는지 확인합니다. 이미지 안의 글자나 마스터 장식은 검색 범위에 포함되지 않습니다. |
| 정렬 버튼이 비활성화됨 | 파일 준비 완료와 요소 선택을 확인합니다. 선택 영역 기준은 같은 슬라이드에서 2개 이상, 슬라이드 기준은 1개 이상 필요합니다. |

| 드래그한 범위의 일부 요소가 빠짐 | 회전된 경계나 그룹 경계 전체가 사각형 안에 들어왔는지 확인합니다. |

| 텍스트 높이 조정에서 일부 항목을 건너뜀 | 그룹 내부·세로쓰기·다단 텍스트 등 지원 범위를 확인합니다. |

### 텍스트 서식

텍스트 박스를 선택하면 작업 영역 상단 **workspace-bar**의 가로형 **텍스트 서식** 도구에서 글자 크기(1~400pt)와 볼드를 조절할 수 있습니다. 크기 입력 후 Enter 또는 다른 곳을 클릭하면 적용되며, − / + 버튼은 1pt씩 조절합니다. **B** 버튼은 볼드를 켜거나 끄며 적용 상태를 강조 표시합니다. 체크된 슬라이드에서 선택한 텍스트 박스 전체에 적용되며 텍스트 내용은 바뀌지 않습니다. 크기와 볼드는 각각 독립적으로 적용합니다. 크기가 서로 다르거나 원본 서식을 상속하면 입력란에 “—”를 표시하고 툴팁으로 “혼합 또는 상속”을 안내합니다. 이때 크기를 직접 입력하면 − / + 버튼도 사용할 수 있습니다. 변경은 미리보기와 다운로드한 PPTX에 반영되며 실행 취소할 수 있습니다.

### 실행 취소·다시 실행

`Ctrl+Z`로 실행 취소하고 `Ctrl+Y`로 다시 실행합니다. 오른쪽 실행 취소·다시 실행 버튼도 사용할 수 있습니다. 이동, 정렬, 텍스트 서식, 텍스트 박스 맞춤, 삭제, 가이드 편집에 적용되며 최근 25개 변경을 보관합니다. 실행 취소 후 새 편집을 하면 다시 실행 이력이 초기화됩니다. 입력란을 편집 중일 때는 브라우저의 기본 입력 취소 동작을 유지합니다.

### 크기·색상·레이아웃 일치 조건

미리보기 상단의 **크기·색상·레이아웃 일치**를 켜면 플로팅 박스가 열립니다. 옆의 **▾** 버튼으로 다시 열 수 있습니다.

- **크기**: 너비와 높이를 비교합니다.
- **색상**: 채우기·테두리·글자색을 비교합니다. 원본 서식과 테마가 다르면 화면상 같은 색도 제외될 수 있습니다.
- **레이아웃**: 위치·회전·반전·그룹 내부 배치를 비교합니다.

처음에는 세 조건 모두 체크되어 있으며, 체크한 조건을 모두 만족해야 선택됩니다. 조건 변경은 다음 클릭·영역 선택부터 적용되고 기존 선택과 문자열 검색에는 영향을 주지 않습니다. 모두 해제하거나 일치 기능을 끄면 기존 좌표·영역 선택을 사용합니다. 바깥을 클릭하거나 Esc를 누르면 박스가 닫힙니다.


## 개인정보처리방침과 이용약관

앱 하단의 **개인정보처리방침**, **이용약관** 링크로 한국어·영어 공개 문서를 새 탭에서 읽을 수 있습니다. Google 로그인 없이 열리며 편집 중인 문서는 유지됩니다. 개인정보처리방침에는 파일·Google 데이터 이용, 브라우저 저장 및 삭제 방법, 선택적 방문 통계 처리를 설명합니다. [OAuth 브랜딩에 등록할 공개 URL](deployment.md#공개-개인정보처리방침서비스-이용약관)

### 최근 파일에서 Google Drive 다시 열기

- **최근 파일**에 로컬 PPTX, Drive PPTX, Google Slides를 함께 표시합니다.
- **Drive 최신 파일 열기**는 연결을 확인한 뒤 해당 파일을 Google에서 다시 읽습니다. 파일 선택기를 다시 거치지 않으며, 필요한 경우 Google 연결 후 이어서 엽니다.
- Drive PPTX의 **보관한 사본 열기**는 마지막으로 성공적으로 불러온 원본을 브라우저에서 엽니다. 인터넷·Google 연결 없이 사용할 수 있으며, Drive 원본에 덮어쓰는 연결은 해제됩니다.
- Google Slides는 파일 참조만 기억하며 **Drive 최신 파일 열기**를 제공합니다.
- 같은 Drive 파일을 다시 열면 기존 항목과 PPTX 사본을 갱신합니다. 로컬에서 연 파일과는 별도 항목입니다.
- 항목 삭제·전체 삭제는 브라우저의 기록과 사본만 지우며 Drive 원본은 삭제하지 않습니다. 이 기능 적용 전에 열었던 Drive 파일은 한 번 다시 열어야 목록에 추가됩니다.
